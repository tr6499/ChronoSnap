# Contributing to ChronoSnap

1. Open an issue or pull request describing the proposed change.
2. Before your first pull request, sign the ChronoSnap
   [Contributor License Agreement](./CLA.md) when prompted by CLA Assistant.
3. Keep changes focused and include relevant tests or validation details.

The repository maintainers operate CLA Assistant through
[cla-assistant.io](https://cla-assistant.io/). To enable signature checks, a
maintainer must publish the contents of `CLA.md` as a GitHub Gist and connect
that Gist to `tr6499/ChronoSnap` in CLA Assistant. Until that setup is
completed, pull requests will not receive automated CLA checks.
